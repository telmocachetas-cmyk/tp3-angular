# 👋 Bem-vindo ao Portfolio Tracker!

Este é o ponto de partida. Comece aqui!

---

## 🚀 Instalar em 5 Minutos

### Windows
```bash
setup.bat
```

### Mac/Linux
```bash
chmod +x setup.sh
./setup.sh
```

### Depois (2 Terminais)
```bash
# Terminal 1: Backend
cd backend && npm start

# Terminal 2: Frontend  
cd frontend && npm start

# Abrir: http://localhost:4200
```
